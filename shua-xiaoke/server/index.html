📖 使用说明

      

        1. 启动后端:node server.js,控制台访问 http://127.0.0.1:3001/ui

        2. 安装扩展:Edge → 扩展 → 开发者模式 → 加载已解压的扩展 → 选择 extension/ 目录

        3. 打开超星 / 学习通 / 智慧树 / U校园课程页,扩展自动接管;按 Ctrl+Shift+S 打开侧边栏对话框

        4. 所有数据仅存本机,不上传任何第三方服务器;接真实模型只需在上方填入自己的接口与密钥
